# GTFS sample feed

The `.txt` files in this directory are the official GTFS example
feed ("sample-feed") published by Google as part of the GTFS
documentation. They describe the fictional "Demo Transit Authority"
serving the equally fictional area around Timbuktu, and are used
here exclusively as test fixtures for the parser.

- Source: https://developers.google.com/static/transit/gtfs/examples/sample-feed.zip
  (linked from the GTFS examples page,
  https://developers.google.com/transit/gtfs/examples/gtfs-feed)
